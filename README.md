# NA TRADES Web

Website for NA TRADES and the course **Understand The Logic of Time & Price** (ICT · Quarterly Theory · Fractal Model).

Built with Nuxt 4 and Tailwind CSS 4.

## Run locally

Requires Node.js 22.12 or later and pnpm 10.

```bash
pnpm install
pnpm dev     # http://localhost:3000
```

## Pages

| Page | What it is |
| --- | --- |
| `/` | Who NA TRADES is, trading systems, market prices, latest articles, free videos |
| `/about` | The full story and how the framework fits together |
| `/blog`, `/blog/[slug]` | Articles |
| `/free` | Free videos, free PDF and social links |
| `/course` | Course details, modules, plans and FAQ |
| `/enroll` | Sign-up form |

Copy for every page (EN/TH) is in `app/data/i18n.ts`.
